# Assessing Neuroinflammation in Mouse Models of Neurodegeneration using Single-Cell RNA Sequencing


In this project, I investigated how microglia—the brain’s resident immune cells—become activated during neuroinflammation and how this may contribute to neurodegeneration. 
I used the IKKCA/WT mouse line, a model designed to examine altered NF-κB signaling, a central pathway that regulates immune and inflammatory responses. 
Using single-cell RNA sequencing, I generated, integrated, and clustered high-dimensional gene-expression data to identify cell populations and characterize inflammation-associated changes in microglia. 
This work helped clarify how dysregulated NF-κB signaling may shape microglial behavior and the broader neuroinflammatory environment.
